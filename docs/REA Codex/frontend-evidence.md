Audit date: 21 October 2026 (Asia/Kolkata). Scope: current working-tree source in `web/src`, `api`, associated nginx config, and selected legacy Streamlit exports. Analyst responsibility: frontend workflows and their API contract. No production or staging requests, credentials, external mutations, or database reads were used for this component. This file is source-level companion evidence for the wider REA investigation; it does not claim that a browser REA session was performed by this analyst.

## Evidence boundaries

- **Implemented in source** means an executable route/component/function is present; it does not establish deployment or data completeness.
- **Partial** means a narrower implementation exists than the broader capability a buyer might expect.
- **Absent in inspected surface** means the inspected React route table/API endpoint inventory does not expose it. It does not establish absence in other company products, private integrations, or future branches.
- **Runtime unknown** covers actual availability, latency, entitlements, data coverage, device behavior, and accessibility conformance until a controlled browser/session test is completed.
- The repository was already substantially modified, including API, ETL, and React source. This audit describes that working tree, not a verified release commit. No application source was edited by this analyst.

## Current interaction and architecture

React routes comprise library, search, schedule, overview, explorer, crosstab, trends, comparison, changes and preview (`web/src/main.tsx:37-70`). They lazy-load through Suspense. React Query caches endpoints for five minutes and retains them for thirty; busy responses receive more retries (`web/src/main.tsx:73-77`; `web/src/api.ts:116-144`). Data fetching uses same-origin cookies; a 401 redirects to `/auth/dev-login` (`web/src/api.ts:70,93-95`). The latter route is only enabled under `APP_ENV=local` (`api/main.py:54,397-405`); production OIDC completion is not demonstrated by these routes.

The API serves wave books, prepared dashboards, trend series, search catalogue, comparison and two-cut crosstabs. Many responses are prebuilt files or cached JSON; ad hoc work has bounded build slots, queue waits and cache memory (`api/main.py:65-78,249-274,305-381`). Nginx can serve prepublished gzipped payloads after a session check (`deploy/nginx.conf:30-62`). This is a material performance-oriented design asset, but measured production concurrency is outside this audit.

## Capabilities absent in this inspected React/API surface

These are product opportunities to validate against actual target customers and competitor evidence, not a requirement to copy every feature.

- Team spaces, governed sharing permissions, comments/annotations and approval workflow.
- Saved reusable audiences, behavioral segmentation, arbitrary question-by-question cross-analysis.
- User-authored dashboards and pinned reports, complete revision history, scheduled buyer reports/alerts.
- Generative narrative/copilot, qualitative open-text coding, multilingual conversational analysis.
- Sales/receipt/retailer POS, media exposure, loyalty/CRM and campaign activation workflows. Survey platform provenance is not evidence these external data products are integrated.
- Validated forecasting, causal measurement, conjoint, price elasticity or demand simulation.
- Public customer API with API-key/OAuth scopes, client SDK, quotas and customer-facing documentation. Internal FastAPI/OpenAPI endpoints alone do not establish such a commercial offering.

## Preserve the existing advantages

Do not rebuild capability already present: corrected/synonym-aware cross-survey search, harmonised-measure grouping, wording-version guards, proper routed-question denominators, explicit small cells, prior/last-year status, statistical movement curation, source lines, URL state, image/CSV export and precomputed delivery are substantial foundations. Strengthen consistency and make their methodology auditable before adding a broad AI interface.

## Suggested execution order

1. Entitlement parity review, provenance correctness, significance assumptions and export denominator correctness.
2. Durable saved analysis/workspaces, native business exports and configurable alerts.
3. Governed reusable audiences and a typed analytical service with audit trail.
4. Cited descriptive copilot, evaluated against gold questions and malicious/ambiguous prompts.
5. External behavioral data partnerships and predictive tools only where data rights, scientific validation and customer demand support them.

Release gates should include exact query/wave/base provenance, screen/export parity, wordings/routing compatibility, cross-user authorization tests, statistical fixtures, accessible interaction checks and a representative live browser path. Source implementation status must remain separate from deployed readiness.
